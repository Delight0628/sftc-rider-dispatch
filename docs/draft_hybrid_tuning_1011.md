# 草稿：Hybrid 训练保护机制调参（2026-10-09/10，待确认后并入 project.md）

> 状态：草稿。按项目惯例，方案先记录于此，待用户确认后再更新 project.md。

## 1. 背景：两轮真实训练的观察

### 首轮（guoluo_hybrid_1009，200 iters，旧机制）
- neural 全程 0.555-0.660，0/20 轮赢 linear（0.701）
- 机制缺陷三连：lr 无下限减半锁死（≈4e-6）、best 从未保存致回滚空操作、eval seed 漂移不可比

### 次轮（guoluo_hybrid_1010，400 iters，修正机制：lr_min=1e-5 / init 回滚兜底 / 固定 eval seed / n_step=8 / recent 采样）
- **best 0.6726 @ iter 90**，final 0.666 > linear 0.662，8/40 轮 ≥ linear，40/40 轮赢启发式（0.542）
- 修复项全部按设计工作（lr 下限钳制日志、init 回滚生效、loss 降至 0.2-0.3）
- **新瓶颈**：30-iter 循环震荡（0.666→0.649→0.641→回滚到 best），回滚保护"防变坏"有效但**锁住上限**——
  权重每离开 best 邻域即被拉回，无法持续爬升突破 0.6726

## 2. 本轮改进（已实现）

| 配置 | 旧 | 新 | 依据 |
|---|---|---|---|
| `rollback_patience` | 2 | 4 | 30-iter 循环 = 2 轮即回滚；放宽到 4 轮（40 iters）给学习留空间 |
| `lr_min` | 1e-5 | 5e-5 | 钳制后步子过小（学习≈冻结）；提高下限保持续学习率 |
| `rollback_grace_evals` | （无） | 3 | 新 best 后 3 轮宽限期跳过回滚/减半，允许逃离 best 邻域探更高点 |

实现：`hybrid/trainer.py`（grace_left 状态机）、`environments/delivery_config.py`（配置）；
`docs/hybrid_implementation.md` §5/§8 已同步。

## 3. 本轮训练方案

- **起点**：预置 `edge_net_last.npz` = 1010 的 best（0.6726 权重）续训（新 run 目录，不混口径）
- 温度：temp_start=0.3 → 0.1（续训精炼为主，保留少量探索）
- 400 iters × 12 ep（6 workers × 2），B1.small
- run 目录：`runs/guoluo_hybrid_1011/`
- **终止判据（自主迭代）**：连续 2 轮训练 best 无提升 → 判定当前手段耗尽，停止并总结

## 4. 1011 run 实测（2026-10-10，200/400 iters 判决终止）

- 从 1010 best（0.6726）续训，但 eval 全程困 0.575-0.616（均值 0.597），从起点跌落不返
- **假设证实：TD 更新噪声主导，净效应是破坏而非爬升**；1010 的 0.64-0.67 带是
  "回滚钉住幸运快照"的产物，而非学习持续爬升
- **放宽保护（patience 4 / grace 3）方向错误**——丢掉钉住效应后权重滑向 0.60 吸引子
- 附带发现：best_score 不继承上一轮（初始 -1e9），低分 eval 也刷新 best

## 5. 1012 run 方案（收紧 + 降噪，已实现）

| 配置 | 1011 | 1012 | 依据 |
|---|---|---|---|
| lr | 1e-3 | 5e-4 | 漂移减半，减少对好权重的破坏 |
| updates_per_iter | 8 | 4 | 破坏性更新次数减半 |
| batch_size | 64/96 | 96 | 梯度噪声↓ |
| rollback_patience | 4 | 2 | 恢复"钉住高点" |
| rollback_grace_evals | 3 | 0 | 关闭宽限（钉住优先） |
| lr_min | 5e-5 | 1e-5 | 回调，配合钉住 |
| resume_best_score | （无） | 0.6726（launch 覆盖） | best 基线继承，回滚目标锁 1010 best |

- 起点：仍从 1010 best 权重（edge_net_last.npz 预置）
- 判据：若 1012 能维持 0.67+ 并刷新 best → 方向有效；若仍跌落 → TD 目标本身需改
  （第三轮候选：n_step 16 / 优先级回放 / realized_utility 口径加 shaping）

## 5.5 1012 run 实测（2026-10-10，400/400 完赛）

- 0.649-0.666 带稳定（均值 0.658），vs 1011 均值 0.597 —— **"收紧+降噪"改进 +0.06，方向验证有效**
- 但 0.666 九度止步，未破 best 基线 0.6726（best 保持 1010 权重）
- **0.666 天花板归因**：回滚到 0.6726 权重后每次 eval 前 10 iters×4 次 lr_min 微更新
  漂移 -0.007；0.66 平台 = 12 维线性先验水平，64 hidden 小网络表达上限

## 5.6 1013 run 方案（质变组合拳，已实现）

| 配置 | 1012 | 1013 | 依据 |
|---|---|---|---|
| hidden_dim | 64 | 128 | 突破表达瓶颈（0.66 平台 = 容量上限） |
| n_step | 8 | 16 | 履约延迟奖励长程回填 |
| updates_per_iter | 4 | 2 | 更新噪声再减半 |

- 维度变更不续训，从 warm-start 重新出发（1010 经验：90 iters 可到 0.67 平台）
- 判据：破 0.6726 → 继续精调；不破 → 判定当前特征/目标下方法到顶，收尾总结

## 5.7 1013 run 实测（2026-10-10，400/400 完赛）与迭代收尾判定

- **best 0.6726 @ iter 80**，与 1010 的 0.6726 打平；0.673 平台十次复现（80/130/160/200/240/270/300/330/360/390）
- 带形态大幅改善：0.658-0.673（均值 0.665），≥linear 13/40 轮（1010: 8/40，1012: 10/40）
- **上限归因结论**：容量翻倍（64→128）+ 目标加倍（n_step 8→16）+ 噪声减半（updates 4→2）
  后 best 仍钉在 0.6726 —— 上限来自**学习目标/特征本身**（realized_utility 口径、
  12 维边特征信息量），而非模型容量或优化侧
- **迭代收尾判定**：优化侧手段已穷尽（容量/目标/噪声三维试验完毕，best 连续两轮
  打平 0.6726，边际收益 +0.06 → +0.007 → 0）。继续调参不再产生有效改进。

## 8. 新数据实验（2026-10-13，shanghai_hybrid_1016）

### 8.1 数据核查（rl_hybrid_dispatch_data_20261008.csv）

- **量级**：30000 单 × 72 列，全国 20+ 城市（`super_city_name`），与双塔/D&W 训练同源；
  配套交付说明 `RL数据交付说明_20261013.txt`。
- **特征核查结论：满足训练要求**。核心字段全覆盖：order_time / expect_time / 经纬度 /
  骑手实时位置与状态 / 载单量等；时间戳为 epoch 秒，坐标为 WGS84 系。
- **接入修复 3 坑**（commit c640e5f，`environments/real_data_loader.py`）：
  1. **`\\N` 空值短路 due 链**：数仓空值标记 `\\N` 被 `_first` 当有效值，due 取到非 epoch
     字符串→全部走 ready+40 兜底（丢 expect_time 真实 due）。修复：`_NULL_MARKS` 扩展
     （含单/双反斜杠）+ `_first_due` epoch 量级校验（>1e8），due 走 expect_time，
     slack 中位 119.6min（原兜底口径 40-70min）。
  2. **csv.Sniffer 判别失败**（72 列）：`.csv` 直接 `csv.DictReader` 逗号直读。
  3. **跨城坐标拉爆投影**：全国订单同池导致 geo 投影网格失真；
     `hybrid_train.py --real-city`（如 `--real-city 上海市`）按 `super_city_name` 过滤
     订单行+骑手行，单城口径训练。

### 8.2 训练协议

exp-b 16 维方案原样迁移：400 iters / 12 ep/iter / 6 workers / seed 0 / eval seed 90000 /

--real-city 上海市 --real-max-pool 2000`。基线口径（同数据 2000 单池）：**linear L=0.820、edd=0.595**。

### 8.4 判定

last 400）已归档本地，仪表盘已并入。
